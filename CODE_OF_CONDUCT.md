# Code of Conduct

## Our pledge

We aim to make this project a respectful and constructive space for research-software collaboration.

Contributors and users are expected to communicate professionally, give and receive feedback constructively, and respect the public/private data boundary of the project.

## Expected behaviour

Examples of expected behaviour include:

- using welcoming and inclusive language;
- being respectful of different viewpoints and experience levels;
- giving constructive technical feedback;
- focusing criticism on code, documentation, tests, and scientific interpretation rather than individuals;
- avoiding the disclosure of confidential or private data.

## Unacceptable behaviour

Examples of unacceptable behaviour include:

- harassment, intimidation, or discriminatory language;
- personal attacks;
- publishing private or confidential information without permission;
- committing private facility data, raw experimental recordings, or proprietary operational information;
- making unsupported scientific or safety-critical claims from the repository outputs.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, documentation, code review, and related project communication.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code of conduct. Repeated or serious violations may lead to being blocked from further participation.

## Attribution

This is a lightweight project-specific code of conduct adapted for a small public research-software repository.
